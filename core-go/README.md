# 下载核心 · Go 验证版

这是**下载核心验证版**。

定位：**只做"把 URL 后面的字节，原样搬成本地文件"**。
不含界面、队列、浏览器扩展、托盘、通知等任何"软件外壳"。

目的：**先用 Go 把多线程 + 动态分段跑通、把坑踩出来**，
产出的规则和测试，就是以后 Rust 正式版的施工图。

---

## 直接拿来下载（就一个程序）

双击 `下载.exe`：

- 弹出 CMD 窗口；
- 提示输入网址，粘贴后回车；
- 文件下载到**当前文件夹**（也就是 exe 所在的目录）；
- 全程写详细日志到 `download.log`，出错就翻它最后几行。

**不联网自检**

在"请输入下载网址"后面输入 `selftest` 回车，它会起一个本地测试服务器，完整下一遍并校验。

**重新编译**

```bash
go build -o 下载.exe ./cmd/get
```

**不编译直接跑**

```bash
go run ./cmd/get
```

## 目录结构

| 文件 | 作用 |
| --- | --- |
| `engine.go` | 引擎与调度：探路、起工人、补员、拼装、收尾 |
| `part.go` | 分段 + **安全区**（"边下边分、实时加人"的核心） |
| `split.go` | 开局的均匀切分（尊重最小块） |
| `http.go` | 探路、分段请求、"对暗号"、空闲超时、文件名解析 |
| `store.go` | 续传记录（**原子写入**，写一半断电不会坏） |
| `assemble.go` | 把各分段临时文件按顺序拼成成品 |
| `limiter.go` | 全局令牌桶限速 |
| `errors.go` | 错误分类：可重试 / 致命 |
| `paths.go` | 从网址猜文件名、清洗非法字符 |
| `testserver/` | 可控测试服务器（能模拟不支持分段、故意报错、限速、卡住、换文件） |
| `cmd/get/` | **唯一的那个测试程序**（双击 exe 的入口） |
| `engine_test.go` | 端到端测试 |

## 备注

- 分段下载时强制 `Accept-Encoding: identity`，否则字节范围会错位。
- 临时目录按目标文件路径派生，保证"同一个目标文件 → 同一份续传状态"。
- 续传前会校验分段临时文件是否还在、是否够长，防止"记录还在、数据没了"导致坏文件。
- 引擎通过 `Callbacks.OnLog` 输出详细日志（DEBUG/INFO/WARN/ERROR）；测试程序把它写到 `download.log`。
